About the platform

About ABICS AMS

The ABICS Auditorium Management System is a student-built platform for Air Base Inter College, Mushaf, Sargodha. It brings event scheduling, seat reservation and entry passes into a single, easy-to-use system for students, parents and college administration.

Built entirely with HTML, CSS and JavaScript, the system stores data locally in your browser and issues a digital, QR-coded entry pass for every confirmed reservation.
